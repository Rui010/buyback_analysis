## 依頼1：中計抽出プロンプトの改善提案

下流で原文PDFと照合したところ、上流の抽出に原因があるとみられる誤りが、次のパターンで繰り返し見つかりました。下流では個別に削除・修正しましたが、同じ誤りが今後の抽出でも起きるため、`midterm_plan_native.md` と `midterm_plan.md` への反映をご検討ください。

### 1. 単年度の業績予想を中計の目標として抽出している（優先度：高）

| 例 | 内容 |
|---|---|
| 7271 安永（2025-08-06・10-17・11-14） | 「業績予想の修正」の開示。2026年3月期の売上・利益・EPS の予想が、計画名「第７次中期経営計画」で `ok` になっていた |
| 9331 キャスター（2025-10-10） | 中計資料に載っていた 2026年8月期の通期予想を目標として抽出 |
| 6753 シャープ（2025-05-12・2026-05-12） | FY2027 が最終年度の中計に併記された、FY2025・FY2026 の単年度予想を抽出 |
| 8783 abc（2026-04-14） | 中計の進捗報告にある「通期 売上高目標 37.25〜57.25億円」（今期の予想レンジ）を抽出 |
| 3823（2025-04-14） | 上期決算説明資料の今期予想と前年からの増益額を抽出（FY26 以降は「イメージ図」と明記） |

指示案：
- 「通期業績予想」「業績予想の修正」「今期予想」「○年○月期予想」など、単年度の業績予想は中計の目標として抽出しない
- 中計の最終年度または中間年度の目標として明示された数値だけを抽出する
- 資料全体が業績予想の修正のお知らせなら、指標を抽出しない（`no_targets`）

### 2. 中計本体ではない開示から指標を抽出している（優先度：高）

| 例 | 資料の中身 |
|---|---|
| 3565（2026-04-01）、8367（2026-05-20）、5076（2025-05-14） | 中計の訂正のお知らせ。訂正前後の図や、訂正対象の実績値が指標になっていた |
| 4568 第一三共（2026-05-18） | 役員報酬（業績連動株式報酬）の評価指標のお知らせ |
| 3541 農業総合研究所（2025-04-25） | 中計説明会の質疑応答集（「中計ではシステム開発費2億円」という発言） |
| 6178 日本郵政（2025-11-14） | 次期中計の骨子（数値目標なし） |

指示案：
- 訂正のお知らせ・役員報酬・質疑応答集・骨子のように、中計の数値目標を新たに示していない開示からは指標を抽出しない
- 訂正のお知らせで目標値そのものが訂正された場合は、訂正後の目標値だけを抽出し、何の訂正かを `plan_name` などで区別できるようにする

### 3. 期間累計の目標を単年度の目標として抽出している（優先度：高）

| 例 | 内容 |
|---|---|
| 9531 東京瓦斯（2025-10-29） | 「営業CF（3カ年計）1.2兆円」「株主還元 2,000億円」（3年間の累計）を `target_year` なしの指標として抽出 |
| 2207 名糖産業（2026-05-14） | 「自己株式の取得 35億円」（計画期間の累計） |

下流では年度の実績と比べてしまうため、進捗が誤って表示されます。指示案：
- 期間累計の目標は、`target_period_label` に「3カ年累計」「2026〜2028年度累計」などの原文を入れ、累計であることが分かるようにする（前回お願いした出力例の確認と同じ件です）

### 4. 参考資料の統計を目標として抽出している（優先度：中）

| 例 | 内容 |
|---|---|
| 6178 日本郵政（2025-11-14） | 参考資料の国内人口の見通し（7,310万人・6,213万人、2025年・2040年）を指標として抽出。下流で経常利益・純利益に誤って割り当てられた |

指示案：
- 外部の統計・市場予測・参考資料の数値（人口、市場規模など）は、会社の目標ではないため抽出しない

### 5. 長期目標と中計目標が区別されていない（優先度：中）

| 例 | 内容 |
|---|---|
| 8361 大垣共立銀行（2025-09-25） | 「中期経営計画計数目標」と「長期計数目標」が両方あり、下流で長期目標（純利益250億円・ROE 8%）が中計目標として使われた |
| 7790 バルコス（2025-11-14） | 長期ビジョン「300億企業」（年度なし）と、中計の2028年の目標（売上100億円）が別の行として混在 |

指示案：
- 長期ビジョン・長期目標の数値には、中計目標と区別できる印を付ける（例：`horizon: "long_term"`）。区別が難しければ、中計の計画期間内の目標だけを抽出する

### 6. 画像だけの資料の読み誤り（優先度：低）

| 例 | 内容 |
|---|---|
| 4568 第一三共（2026-05-11） | スキャン画像だけの説明会資料から、売上1兆円・ROE 20% など資料にない値を抽出（正しくは売上収益3兆円・営業利益6,000億円） |

指示案：
- テキストを含まない（画像だけの）資料から抽出した場合は、そのことが分かる印を付ける（例：`source: "image"`）。下流で優先的に確認します

## 依頼2：計画期間の表記（別チケット）

目標年度と同じく、計画期間（`plan_start_year` / `plan_end_year`）にも「年度」と「決算期末の年」の違いがあります。たとえば3月決算の「2026〜2028年度」の計画は、決算期では 2027年3月期〜2029年3月期です。下流では目標年度を決算期末の年に直したため、開始年だけ年度表記のまま残り、計画の経過率が1年ずれる可能性があります。

### お願いしたいこと

`midterm_plans` に、計画期間の原文表記と正規化した決算期末を追加できないでしょうか。テーブル・既存の列の意味は変えません。

| 項目 | 内容 | 例（3月決算「2026〜2028年度」） |
|---|---|---|
| `plan_start_period_label` | 開始の原文表記 | `"2026年度"` |
| `plan_end_period_label` | 終了の原文表記 | `"2028年度"` |
| `plan_start_fiscal_end` | 開始年度の決算期末（`YYYY/MM`）、判断できなければ `null` | `"2027/03"` |
| `plan_end_fiscal_end` | 終了年度の決算期末（`YYYY/MM`）、判断できなければ `null` | `"2029/03"` |

変換の方針は、目標年度と同じ（資料内の定義や対応表記で確認できた場合だけ変換、決算月だけで断定しない）でお願いします。

### 確認したいこと

1. 列の追加になるため、対応できるか・時期の目安
2. 既存の `plan_start_year` / `plan_end_year` は、目標年度と同じく資料に書かれた年をそのまま持っているか
3. 資料に期間が書かれていない場合、中計の名前（「中期経営計画2027」など）や目標年度から推測して埋めているか、`null` にしているか。下流では期間が空であることを「中計本体ではない可能性」のサインとして使っているため、推測で埋める場合は区別できると助かります
4. 開始・終了の片方だけ分かる場合に、分かる方だけ入れてもらえるか

既存データの再抽出は不要です。急ぎではないので、依頼1の後で構いません。
